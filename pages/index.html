Multiplex64, or Mux64, is a basic Web Tools site made as a personal project.

Over the past few months, it looks like we're starting to get some traffic from a number of US states as well as other countries. Thank you all for supporting this personal project. Any and all feedback is always welcome.

Announcement:
We experienced a DDoS attack on UTC 2026-07-10 15:25:20 that lasted 35 minutes, from an unknown user operating in Canada's Toronto region.

Over 65,000 Requests were sent during this time. That's over 30 requests per second!

A DDoS attack is an attack where an extreme number of requests are sent to a server intentionally to overload the system and degrade response times for other users.

Apologies for any downtime or degraded performance at the time.

Based on logs, it appears that this user was sending rapid requests for .webp files related to indian spiritual figures, on our HTML Playground.

It is likely that someone could have mistakenly created a script that caused this behavior, so I will not be revealing their IP Address. However, if this continues, I may have to ban the attacker's IP.

Stay safe out there, programmers!
